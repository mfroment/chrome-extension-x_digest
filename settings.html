Search syntax

The timeline search box takes a query, not just text. Terms are combined with AND by default (write it or leave it out); use OR and parentheses to group. The syntax follows the usual field:value convention, so it should feel familiar.

helloMatches anywhere — post text, author, summary, theme, event name or venue.
"hello world"Quotes mean this text is in the post body — never the summary, author or theme.
@handleThe poster, the reposter, or a repost's original author.
likes:>10Also >=, <, <=, =. A bare number means equals: likes:20.
replies:>5
reposts:>10		Same comparisons, on the reply and repost counts.
is:read is:unread
is:liked
is:repost is:reply		Filter by state or kind of post. is:liked matches the ♥ shown on the card (the original's state on a repost); use -is:liked for the ones you haven't liked.
has:media
has:link		Only posts carrying an image/video, or a link.
tier:full tier:summary
tier:other tier:none		 Filter by how the analysis classified the post — full-detail, summary, off-theme, or none for posts not analyzed yet (the red-bordered cards).
-term / NOT termExclude. Works on any term: -@spammer, -is:repost.

Example: (@alice OR @bob) likes:>10 "hello world" — posts from either author, with more than 10 likes, whose body contains that phrase. The Unread only and Analyzed only buttons are applied on top of whatever you type, so they stay out of the query. The counter in the header reads N of M posts, where N is what the filters currently leave showing — the same set the right-click bulk actions act on. If a query can't be parsed (an unclosed bracket while you're still typing), it falls back to a plain text search.

Right-click shortcuts

Several parts of the digest hide their less-frequent actions behind a right-click, to keep the interface light. Here is the full list.

Author name Filter the timeline to that author (their posts and their reposts).
🔁 marker / “Reposted by …” Filter to the reposter instead of the original author.
✓ read check “Read up to here” — mark this post and everything older as read.
Search box (while searching) Act on the whole search result: mark every matching post read, or re-analyze them (discards their summary/theme/event and recomputes — handy for testing a prompt change on a small selection).
“N unread” count Mark posts unread from a chosen date/time — the catch-up reset.
✨ Analyze Re-analyze a subset: event posts only, all, off-theme, unread, or unread off-theme. A plain click only analyzes posts never analyzed before.
🔄 Sync Sync further back than usual: 24 hours, 3 days, 7 days, or a date/time.
Event source links (Events tab) “Open in X”. A plain click jumps to the post in the Timeline instead.

Anything that changes read state or an event flag can be undone with the ↶ Undo button or Ctrl/⌘+Z — its tooltip names exactly what will be reverted.

Data (backup)

Everything lives only in this browser — clearing browser data or removing the extension wipes it. Export a JSON backup of your captured posts and read/like/hidden state; import it into a fresh install to restore. The backup does not include your API key.
