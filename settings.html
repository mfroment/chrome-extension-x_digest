Right-click shortcuts

Several parts of the digest hide their less-frequent actions behind a right-click, to keep the interface light. Here is the full list.

Author name Filter the timeline to that author (their posts and their reposts).
🔁 marker / “Reposted by …” Filter to the reposter instead of the original author.
✓ read check “Read up to here” — mark this post and everything older as read.
Search box (while searching) Mark every post matching the current search as read.
“N unread” count Mark posts unread from a chosen date/time — the catch-up reset.
✨ Analyze Re-analyze a subset: event posts only, all, off-theme, unread, or unread off-theme. A plain click only analyzes posts never analyzed before.
🔄 Sync Sync further back than usual: 24 hours, 3 days, 7 days, or a date/time.
Event source links (Events tab) “Open in X”. A plain click jumps to the post in the Timeline instead.

Anything that changes read state or an event flag can be undone with the ↶ Undo button or Ctrl/⌘+Z — its tooltip names exactly what will be reverted.

Data (backup)

Everything lives only in this browser — clearing browser data or removing the extension wipes it. Export a JSON backup of your captured posts and read/like/hidden state; import it into a fresh install to restore. The backup does not include your API key.
